# Savique - Personal Budget App

**Savique** is an Android application designed to help users track expenses, manage budget categories, and set monthly financial goals.

##  Features
- **User Authentication:** Secure registration and login using RoomDB.
- **Budget Dashboard:** Real-time visualization of monthly spending vs. user-defined goals.
- **Expense Tracking:** Add expenses with descriptions, amounts, timestamps, and photo receipt previews.
- **Category Management:** Custom category creation to organize spending.
- **History & Filtering:** View and filter transaction history by user-selected date periods.

##  Tech Stack
- **Language:** Kotlin
- **Database:** Room (SQLite)
